# Barberia-App

Aplicación móvil desarrollada para Android nativo, destinada al catálogo, reserva y gestión de servicios de barbería. Proyecto desarrollado para la materia Laboratorio VI de la Universidad Nacional de Santiago del Estero (UNSE).


## Características
* Catálogo de Cortes y Servicios: Visualización detallada de los estilos de corte y tratamientos disponibles.
* Diseño moderno y limpio mediante componentes adaptables en Jetpack Compose.
* Estructura modularizada para pantallas de inicio, catálogo y detalles.

## Stack Tecnológico
* Lenguaje: Kotlin
* UI Framework: Jetpack Compose
* Navegación: Navigation Compose
* IDE: Android Studio
* SDK Mínimo: API 24

## Instalación y Configuración
1. Clonar el repositorio: 
            `git clone` https://github.com/Ramiro456/Barberia-App
2. Abrir el proyecto en Android Studio.
3. Sincronizar el proyecto con Gradle (Sync Project with Gradle Files).
4. Ejecutar en un emulador Android o dispositivo físico (API 24+).
